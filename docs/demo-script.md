# Demo script

1. Open the capability catalogue and show that observed, inferred, and proposed claims are visibly distinct.
2. Open `Assess Company Credit Risk` and show its purpose, boundaries, contract, provenance, and unknowns.
3. In the playground, choose **Northstar Components Oy** and **Supplier**.
4. Run the brief. Point out the financial trend, synthetic risk drivers, valuation context, uncertainties, and next questions.
5. Explain that the brief composes four independent capabilities; the same capabilities remain reusable through other products and agent workflows.
6. Show `/healthz` and MCP `tools/list` to demonstrate that the capability model has a working software realization.
